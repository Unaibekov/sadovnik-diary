# Запуск на телефонах в РФ без Expo-сервисов

Приложение не зависит от внешних CDN или API во время работы. Если на телефоне не открывается QR из Expo Go, чаще всего проблема в доступе к сервисам Expo или в сетевом туннеле. Надежный вариант для проверки на телефоне - открыть web-сборку по локальному IP компьютера.

## Локальная web-сборка

1. Подключите компьютер и телефон к одной Wi-Fi сети.
2. Запустите:

```bash
npm run phone:web
```

3. В терминале появится строка вида:

```text
Phone: http://192.168.1.10:4173
```

4. Откройте этот адрес в браузере телефона.

Если адрес не открывается, проверьте, что Windows Firewall разрешает входящие подключения для Node.js на частной сети.

## Expo Go без туннеля

Для запуска через Expo Go используйте LAN-режим без облачного туннеля:

```bash
npm run start:lan
```

Телефон и компьютер должны быть в одной сети. Этот режим не решает ограничения самого Expo Go, но не использует внешний tunnel.

## Только браузер

Если нужна раздача уже собранного `dist` без пересборки:

```bash
npm run serve:dist
```
